🍎 Import Apple Health Data

A web page cannot read HealthKit directly. Import a JSON daily summary exported by an iPhone companion, Shortcut, or converter instead.

Or paste a JSON export:

Import Format

Required: version: 1 and a days array. Each day requires a YYYY-MM-DD date. Optional fields are sleepHours, restingHeartRate, hrv, vo2Max, steps, activeCalories, weight, and workouts.

Workouts may include name, type, sets, reps, weight, distance, and duration. Invalid records are rejected before anything is saved.
